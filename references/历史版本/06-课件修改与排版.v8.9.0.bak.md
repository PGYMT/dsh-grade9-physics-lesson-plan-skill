# 课件修改与排版要求

> 版本：v8.9.0｜配套：SKILL.md、01-教案生成要求.md
> 本文件是**修改希沃课件（.enbx）与课件排版**的执行口径（唯一权威）。技术详解见工作区 `00-模板与规范/希沃enbx直接修改技术说明-20260928.md`，选题依据与文献见 `00-模板与规范/物理课件习题选择与字体排版要求-新授课当堂练习.md`，验证坑与复现命令见 `06-工具与提示词/教程/md文件/enbx自动截图识别-经验总结-20260929.md`。本文件与上述文档冲突时，以本文件为准。

## 0. 触发与边界

**什么时候用**：给现有 .enbx 加页（末尾加、中间插）、加当堂练习页、加重点突破页/方法页、给答案加“点一下出现”动画、替换某页图示。
**顺序恒定**：先出教案摘要 → 用户确认 → 再落课件页。课件页内容取自教案的“当堂练习/教学准备”，不另起内容。
**只改副本**：所有改动写在副本上，原件逐字节不动。
**普通 .pptx**：仅当某类页用希沃原生元素确实写不稳时才用 office-pptx 兜底（尚未实测），不作为主线；优先把希沃原生写法用尽。

## 1. 红线（一条不松）

1. 原件逐字节不动，只改副本。
2. 不碰希沃云端：不点“同步”“保存”；拿回本地只走“导出到下载夹”。
3. 不杀希沃进程：优先复用**已在运行且已登录**的实例开新标签；确需重启时用 `swenlauncher.exe` 启动，不要直接跑 `Main\EasiNote.exe`。
4. 不写工作区外路径（/mnt/c、/mnt/d 只读）；往 Windows 送文件用 PowerShell 从 UNC 复制。
5. 每次改完**换新文件名**再打开，绕开希沃按路径缓存标签页的问题。

## 2. 技术要点

### 2.1 结构与页序
- .enbx 就是一个 zip 包。
- **页序**＝`Board.xml` 里 Item（GUID）的先后。
- **第 N 页**＝`Slides/Slide_N.xml`（N 从 0 起）；`Slide` 的 `Id` 必须等于 Board 第 N 项 GUID。
- **素材**＝`Reference.xml` 把 `id://GUID` 映射到 `Resources\GUID.扩展名`，`Hash`＝该文件的 md5。
- **视频**：Slide 里的 `<Video>` 元素带 `<Thumbnail>id://封面GUID</Thumbnail>`，封面就是 Resources 里的一张图；抽帧与封面识别见 01 §0。
- 加页：新建 `Slides/Slide_(新下标).xml`，Board 在目标位置插 Item；中间插页时把 N≥插入位置的 `Slide_N.xml` 依次改名为 `Slide_N+1.xml`（内容与 Id 不动）。
- 元素 Id、页 Id 各自唯一，不得重复。

### 2.2 原生文字（Text）最小骨架
```xml
<Text>
  <RichText>
    <SizeToContent>Manual</SizeToContent>
    <ArrangingType>Horizontal</ArrangingType>
    <VerticalTextAlignment>Top</VerticalTextAlignment>
    <TextLines>
      <TextLine>
        <LineSpacing>4.6</LineSpacing><TextAlignment>Left</TextAlignment>
        <TextRuns>
          <TextRun>
            <Text>题干文字</Text>
            <FontSize>28</FontSize>
            <FontVariants>Normal</FontVariants>
            <FontStyle>Normal</FontStyle><FontWeight>Normal</FontWeight>
            <FontFamily><Source>微软雅黑</Source></FontFamily>
            <Foreground><ColorBrush>#FF000000</ColorBrush></Foreground>
            <Opacity>1</Opacity>
          </TextRun>
        </TextRuns>
        <Lines><LineProperty><StartOffset>0</StartOffset><Length>4</Length></LineProperty></Lines>
      </TextLine>
    </TextLines>
  </RichText>
  <Id>元素GUID</Id><X>70</X><Y>120</Y><Width>820</Width><Height>80</Height>
  <!-- 通用尾巴：Rotation=0 / IsLocked=False / CanClone=False / HasMask=False / RotateOrigin=0.5,0.5 / SaveInfoMetadata / ElementPptxOriginId -->
</Text>
```
- **字号单位就是磅**：正文直接写 `FontSize` 28/32。
- `<Lines>/<LineProperty>/<Length>` 是这一行的字数，**由脚本自动算，不手填**。
- 文本框**不自动换行**：长句按每行约 28 字拆成多个文字块。

### 2.3 原生形状（Shape）最小骨架（参考骨架；当前脚本只生成 Text/Picture，形状需手写或扩展）
```xml
<Shape>
  <Geometry><PresetGeometry><GeometryType>Rectangle</GeometryType></PresetGeometry></Geometry>
  <Background><ColorBrush>#FFFFFFFF</ColorBrush></Background>
  <Foreground><ColorBrush>#FF249087</ColorBrush></Foreground>
  <Thickness>2</Thickness><LineType>Normal</LineType>
  <Adjusts>
    <Adjust><ScaleX>0</ScaleX><ScaleY>0</ScaleY></Adjust>
    <Adjust><ScaleX>1</ScaleX><ScaleY>1</ScaleY></Adjust>
  </Adjusts>
  <Id>元素GUID</Id><X>90</X><Y>140</Y><Width>200</Width><Height>120</Height>
  <!-- 通用尾巴同 Text -->
</Shape>
```
- 椭圆用 `GeometryType=Custom_PPTX_Ellipse`（带 ShapePaths）；直线用 `Custom_PPTX_StraightConnector1`。
- **直线方向由 `Adjusts` 决定，不看 `Path`**：右下斜＝adj0(0,0)+adj1(1,1)；右上斜＝adj0(1,0)+adj1(0,1)。

### 2.4 答案“点一下出现”（动画）最小骨架
动画写在**元素内部**，位置在 `CanClone` 之后、`HasMask` 之前：
```xml
<Animations>
  <Animation>
    <Type>FadeIn</Type><Id>动画GUID</Id><Number>1</Number><Category>Appearance</Category>
    <Trigger>Click</Trigger><TriggerSource></TriggerSource>
    <Duration>3000000</Duration><Delay>0</Delay>
    <AccelerationRatio>0</AccelerationRatio><DecelerationRatio>1</DecelerationRatio><RepeatBehavior>1</RepeatBehavior>
    <Start>0</Start><End>1</End>
  </Animation>
</Animations>
```
- `Number`＝本页内出现顺序（1、2、3…）；`Trigger`＝Click/Before；`Category`＝Appearance/Disappearance；元素出场动画 `Duration` 3000000≈0.3 秒（脚本 anim_xml() 取值），整页幻灯片的 `Duration` 才是 5000000。
- 答案做成**同一页里独立的文字元素＋FadeIn(Click)**，逐条出现；不要做成新页。

### 2.5 母版克隆（首选做法）
1. 在原件里找一页**同类型**页当母版（练习页→练习页；方法/小结页→小结页）。
2. 复制它的元素骨架（坐标、宽高、字体、行距、颜色、编号、横幅、logo、底栏），只换成新文字。
3. 元素 Id、动画 Id 重新生成。
4. 题多就复制文本框整体下移，保持等距。

### 2.6 硬提醒
- 编辑态点 `PageRight` 无效：跳页用左侧“第 N 页”列表。
- 编辑态会把动画元素直接显示出来：验“点击出答案”必须进**授课模式**（独立 4K 全屏窗口，页码 `n/N`，`Esc` 退出）。
- PowerShell 5.1 会把无 BOM 的 .ps1 当 GBK 读：**.ps1 源码保持纯 ASCII**。
- WSL 调 Windows PowerShell 时用 `-EncodedCommand`，避免 `$` 与反引号被吃掉。
- tesseract 读不出彩色底白字、竖排、小字表格：这些交视觉层 `read_image`；必要时先用 media 裁切放大再读。
- 视频必须打进包里并配封面图，不能只填网址；本机 ffmpeg/ffprobe **已可用**：课件视频可直接抽帧（帧数按时长自适应）与转码，封面优先直接取 enbx 内 Thumbnail。
- 写回后必须自检：Board 第 i 项 GUID ＝ `Slide_i` 的 Id。

### 2.7 官方 API 备选路径（非主线）

- 希沃官方只公开「希沃白板客户端 Web API」（easinote.github.io/EasiNote.ClientWebApi.Documentation），**没有公开 .enbx 文件格式规范**。
- 可用接口：ImportEnbx／ImportFile／ImportPptx（导入课件）、InsertSlide（插入页面，可指定插在第几页之前、背景色/图）、InsertElement（插入元素，参数 XML 与 .enbx 元素同源）、InsertText／InsertImage／InsertVideo／InsertAudio／InsertMedia；另有 API v2 的题目卡片等。
- 限制：需要希沃客户端在运行、需要一个网页当宿主；文档为 2021—2022 年版本，未必匹配现用 5.2.4。
- **主线仍是本文件第 2 节「直接改 XML 副本」**：离线、可脚本化、不碰云端。官方 API 仅作备选。

## 3. 内容与排版要求

### 3.1 选题（新授课当堂练习）
1. 紧扣课标与本课时目标，教-学-评一致；不随意拔高或降低。
2. 精选，不拿来主义；不超标、不超前、不照搬。
3. 五性合一：科学性、针对性、典型性、发散性、实用性；不偏、不怪、不繁。
4. 习题≠试题：按知识点线性排列、以基础题为主，不用试卷“7∶2∶1”梯度要求当堂练习。
5. 来源优先级：教材课后题/情境 ＞ 增删改编 ＞ 教辅（本地优先《金学典·同步优学》人教版物理九上）。
6. 不选：偏怪繁、超课标、大杂烩、机械重复、中高考原题整卷。

### 3.2 题型、层次与数量
- 题型（新授课建议）：填空、判断改错、实验探究/简答、作图、简单计算；**尽量少用选择题**。
- 层次：概念形成（基础）→ 知识运用（中档）→ 问题解决（拓展，可选）。
- 数量：一课时 **3—5 题**，以基础层为主；用时 **5—10 分钟**，不挤占新课讲授。

### 3.3 排版硬指标
| 项 | 要求 |
|---|---|
| 字号 | 题干正文 ≥28 磅、标题 ≥32 磅、答案 ≥28 磅 |
| 字体 | 正文 微软雅黑；数字 Times New Roman；口诀/提示 楷体 |
| 主色 | 青绿 `#FF249087`；强调方式 ≤3 种 |
| 版面 | 行距约 1.2；四周留白、内容不顶边；一页一题 |
| 动画 | 每页进入动画 ≤1 个，无闪烁特效；答案点击逐个出现 |
| 原则 | **宁大勿小**：一页放不下就拆成两页，不缩字 |

### 3.4 图片处理
- 能用原生形状画的图（电路图、符号）一律用 Shape。
- 照片类才用图片：优先用原课件/教材原图，抠底、等比缩放后再用。
- 网络图仅在没有原图时使用，裁紧去白边；**绝不整页截图**，也不把网络习题整页转图。

## 4. 标准工作流（9 步）

1. 确认：源课件路径、要加什么页、加在哪两页之间、先看哪一课时。
2. 先查 08-网络资源/ 对应目录有无本地存档；有就复用，没有就联网检索。
3. 提炼候选内容（题目/方法/口诀），**摘要先给用户确认**。
4. 读原件风格：字体、字号、配色、母版页（扫 Slide XML 统计）。
5. 选母版页克隆骨架，按摘要写原生页（Text＋Picture＋FadeIn；形状页需手工）。
6. 装配进副本，命名“<节号><节名>-原生页版.enbx”；原件不动。
7. 脚本自检（见 §6）。
8. 给出“复制到 Windows”的单行命令＋希沃核对步骤。
9. 汇报；本次新页与风格参数留档。

## 5. 两层验证与判读

| 层 | 工具 | 管什么 |
|---|---|---|
| 机器层 | tesseract（`enbx_shot_ocr.py`） | 文字在不在、点击前无/点击后有、页码变没变 |
| 视觉层 | `read_image` | 版式、字号观感、主色、图形正确性、裁切、清晰度、像不像 |
| 都不管 | 脚本自检 | 像素级字号/坐标/越界仍靠生成器自检 |

- 判定：**PASS**（机器层通过）／**MISS**（tesseract 没读到，交视觉层，加 `--strict` 才算失败）／**FAIL**（缺截图、禁止词误现、点击后页码变了；硬失败才非 0 退出）。
- 预期清单写进 `expected_pages.json`：顶层 `meta`；`pages` 按页号列出 `label`（该页人话标签）、`must`／`must_not`（点击前机器层断言）、`visual`（视觉层检查项）；`after_click` 含 `same_page_required`（点击后页码不得变化）、`steps[]`（每步 `clicks`＝点击次数，`must`／`must_not`＝该步后的断言）。
- 编辑态跑 OCR 加 `--no-anim-checks`（编辑态会显示动画元素，答案提前可见）。

## 6. 课件自检清单（课件专用；教案清单见 02 §6）

1. Board 的 Item 数＝Slide 文件数；第 i 项 GUID＝`Slide_i` 的 Id。
2. 元素 Id、页 Id 不重复。
3. 每个文本框坐标在 960×540 内，右边界不超页、不压边（留白 ≥40）。
4. 字号达标：题干正文 ≥28、标题 ≥32、答案 ≥28。
5. 长句已按约 28 字拆块，无右端被裁。
6. 每页进入动画 ≤1 个，无闪烁类；答案用 Click 触发。
7. 所有 `id://` 资源在 `Reference.xml` 里都有映射且 Hash 正确。
8. 原件逐字节未变（改动只在副本）。
9. 希沃实测能打开、能选中并直接编辑新页文字、投影后排看得清。
