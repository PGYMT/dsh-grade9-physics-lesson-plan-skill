# 教学设计细则

> 版本：v8.0.0｜配套：01-教案生成要求.md

## 通用要求
1. 教学目标可评可测：使用“知道、理解、能、经历”等行为动词。
2. 重难点突出：一个课时重点不宜过多，要有明确突破策略；`四、教学重难点` 只写本课总体重点、难点，**不在该板块逐条贴“重点/难点/一笔带过”标签**；具体标注放到**教学过程中该知识点出现的位置**就地写，只标真正需要区分的，并给出大致用时。
3. 环节完整：默认以 PPT 为准；理想环节为 导入 → 新授 → 探究/实验 → 应用 → 小结 → 练习 → 作业；各环节环环相扣；PPT 缺少必要环节时可申请修改/添加，经批准后再调。
4. 教师活动与学生活动对应：必须写学生做什么、答什么。
5. 科学规范：概念、公式、单位、符号、实验操作准确。
6. 联系生活：用学生熟悉的实际情境引入和应用物理知识。
7. 实验与媒体辅助：每课时都要列“实物 / 视频 / 动画 + 替代方案”；优先用实物或学生可操作的教具，拿不到时用慢放视频、模拟动画、数据表或图像替代。演示前先让学生预测，演示后让学生说现象和结论。课件里的关键图片与动画，先用 `read_image` 看懂内容再决定怎么用。
8. 板书结构化：见需求4。本机为 4 块小黑板但**最多用 2 块、默认 1 块**；每块 ≤6 行、每行 ≤6—8 字；优先圈/下划线/填空，不足再用色。
9. 时间分配合理：按 40 分钟一课精确到环节。
10. 作业适量分层：基础题 + 提升题，可设选做。
11. 反思预设：预判学生易错点、可能生成的问题、课堂意外处理。
12. 备课调研：生成前先检索优秀教案与课件，提炼板书/重点/难点/易错/过渡语五维度，摘要先给用户确认（见 01 §0.5）。

## 标注体系（旁批与正文区分）

- 正文（教师语言）不带括号、正常排；
- 学生预设写 `学生：……`；
- 教学旁批（板书、重难点、易混、意图、素材、前概念、安全）统一写 `〔类型｜内容〕`，docx 里用仿宋/楷体、五号、左缩进、灰色或浅底纹；
- 过渡语/衔接用加粗 `过渡语（承接……→ 引出……）：` / `衔接：`，句子本身按正文排。
- 旁批必须落在它对应的那一句话旁边；板书提醒写在**发生板书动作的时机处**，不得写在环节开头，也不得堆在环节末尾。

## 使用注意事项
1. 教案/逐字稿是预设，允许课堂根据学生回答调整。
2. 课件仅为骨架，教案要补足课件缺的条件、情景、逻辑。
3. 默认只交付详案/逐字稿，用于精细备课、公开课或新教师使用；用户另有指定时才输出其他形式。
4. 问题链不要机械堆砌，清晰简单部分不要硬套。
5. 板书不能照抄课件，只保留关键词和关系，并受小黑板容量约束（1—2 块、≤6 行/块、≤8 字/行）。
6. 实验类内容必须注明安全事项。
7. 涉及易混点、前概念时，先判断再解释，不要直接给结论；易混判断题优先引用现成的优秀网络资源并注明来源。
8. 输出前检查：科学准确性、目标达成度、时间合理性、语言可实施性。
9. 课堂时段（下午第一节 / 晚自习 / 体育课后）的应对策略见 `03-教学研究参考.md` 附录 A，按需引用，不要求每节课都写。
10. 板书字迹较差时的替代方案见 `03-教学研究参考.md` 需求 4；本机优先用圈/下划线/填空减少书写量，仍不够再用打印贴、磁条分色、固定版式、电子板书。默认不写进具体教案，用户说明字迹情况时才启用。
11. 标注服务教学，不凑数：板书时机、重难点标签、实物/视频/动画清单只在确有对应内容时写，不为凑格式硬编。

## 教学目标精简要求

1. 句数不变：每个核心素养维度保持原来的 2—4 句，不得合并、增删或拆分句子。
2. 单句精简：每句话只保留“行为动词 + 核心概念/关键条件”，删除以下内容：
   - 同义修饰：“通过……”“能够……”“认识到……”等非必要表述；
   - 解释性从句：“它表示……”“说明……”等，除非该句本身就是理解物理意义类目标；
   - 重复铺垫：生活化展开、背景介绍、过程性描述，除非该句本身就是“体会/感受”类目标。
3. 字数建议：单句尽量不超过 30 字；每个维度总字数控制在 80—120 字左右（公式、符号、单位不强制计入）。
4. 课标动词优先：优先使用“知道、理解、能、经历、体会”等简洁行为动词。
5. 输出前自检：逐条对照上一条，检查是否存在可删但未删的冗余表达。

## 交付前自检

- 若教材版本、课时划分、核心素养侧重点等信息不明确，先询问用户再生成。
- 是否已按 01 §0.5 完成备课调研（优秀教案/课件），并覆盖板书/重点/难点/易错/过渡语五维度；调研摘要是否已给用户确认。
- 检查教学目标是否满足：句数不变、单句精简、无明显冗余；不符合则先修改再输出。
- 检查是否已按需求 1—9 完成。
- 检查是否只输出详案/逐字稿（无正常教案/简案），且详案达到逐字稿程度。
- 检查 docx 是否满足排版要求：标题样式可导航、字号行距页边距合规、表格与公式正确、重读无乱码无丢失、旁批与正文样式可区分。
- 检查问题串/逻辑链是否只在规定情况使用，而且已彻底融入教师活动每一步。
- 检查每处过渡语/衔接是否落在相邻两段之间、是否简短、是否写明衔接对象；是否出现自问自答式设问过渡，是否在弱联系处硬套“承接→引出”。
- 检查重难点标签是否**就地在教学过程相应知识点处**，而不是机械堆在“四、教学重难点”板块。
- 检查每处板书提醒是否写在**发生板书动作的时机处**（而非环节开头），板书是否在提问与小结中被实际指向、使用。
- 检查板书是否满足 1—2 块小黑板、每块 ≤6 行、每行 ≤8 字，是否优先圈/下划线/填空，是否标出每块板与生成顺序。
- 检查旁批是否用 `〔〕` 标注并与正文明显区分。
- 检查教学准备是否列出“实物 / 视频 / 动画 + 替代方案”，演示是否做到“先预测、后说结论”。
- 检查教学过程中每条知识点是否就地标出“重点 / 难点 / 一笔带过”。
- 检查易混判断题/反例是否优先引用现成优秀网络资源并注明来源。
- 检查过渡语是否避开“万能过渡句黑名单”，不硬过渡处是否用了登记句。
- 若为练习课 / 讲评课，是否按“需求9”的结构与环节写足，题目是否来自指定同步教辅或题库。
- 检查是否以 PPT 为准，且任何结构调整已获用户批准。
