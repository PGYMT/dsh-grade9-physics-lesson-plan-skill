### 三处副本

| 位置 | 性质 |
|---|---|
| 仓库 `.agents/skills/<技能名>/` | 权威源头 |
| 用户级 `/root/.dsh/skills/<技能名>/` | 教案生成时实际生效 |
| 工作区 `工作文件/06-工具与提示词/提示词/` | 日常取用：`教案生成要求提示词.md`（由 01+02 自动生成）+ `教学研究参考.md`（=03） |
| 工作区 `工作文件/08-网络资源/教学资源网站索引.md` | 资源网站索引（=05），供检索时直接查看 |

### 配套脚本（工作区 `06-工具与提示词/教程/`）

| 脚本 | 作用 |
|---|---|
| `build_lesson_prompt.py` | 由 01+02 生成工作区 `教案生成要求提示词.md` |
| `extract_enbx.py` | 解包 `.enbx`：提取文本、动画脚本、素材清单，并导出图片/视频 |

### 工作区资源目录

- `08-网络资源/`：网络检索下载的备课资料（`优秀教案/`、`优秀课件PPT/`、`同步优学/九年级上册/`、`板书设计参考/`），其 `README.md` 说明归档约定与版权边界。
- `05-课件与文本/<章节>/课件素材/`：`extract_enbx.py` 导出的图片、视频与素材清单。

## 2. 命名规则

- 文件名不带版本号；版本只在 `SKILL.md` frontmatter 的 `version` 与各 references 文件头部的“> 版本：”两处。
- 备份命名：`<原名不含扩展名>.<被替换版本>.bak.md`，集中放历史版本目录。
- 工作区 `教案生成要求提示词.md` 是生成物，禁止手工修改；要改就改 01/02 后重新运行 `06-工具与提示词/教程/build_lesson_prompt.py`。

## 3. 修改流程

1. 列清单：确定要改的文件（SKILL.md / 01 / 02 / 03 / 04 / 05 / 脚本 / 工作区目录）。
2. 改权威源：先改仓库副本。
3. 备份并同步用户级副本：覆盖前按第 2 节备份到 `references/历史版本/`。
4. 同步工作区：重新生成 `教案生成要求提示词.md`，同步 `教学研究参考.md`（=03）与 `08-网络资源/教学资源网站索引.md`（=05）。
5. 校验：`sha256sum` 比对三处同名文件一致；`grep` 确认无旧文件名/旧版本号残留（排除历史版本目录）；确认 SKILL.md 索引表里每个目标文件与节标题都存在；运行 `organize.py --check` 确认 `08-网络资源/` 判为已归档。
6. 更新第 5 节变更记录。
7. 汇报。
