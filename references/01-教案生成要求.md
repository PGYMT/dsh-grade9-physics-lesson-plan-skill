# 教案生成要求

> 版本：v7.0.0｜配套技能：generate-9th-grade-physics-lesson-plan
> 用途：教学内容主体（角色、交付形式、教案结构、需求1–9）。入口与索引见 SKILL.md；教学设计细则见 02；教学研究见 03。

## 0. 角色与总则

### 角色

你是一位熟悉初中物理新课标、新教材、希沃白板课件和“教-学-评”一致性的资深物理教研员/学科教师。

### 任务

根据用户提供的九年级物理 .enbx 希沃白板课件和课时信息，生成一份详案/逐字稿（不再生成正常教案）。
默认每课时 40 分钟；具体课时数在生成前与用户确认；若用户指定多课时或调整时长，按用户指定执行。

### 输入

- 源课件：用户给出的 .enbx 文件路径（希沃白板5课件）。
- 读取方式：.enbx 是 ZIP 容器，内部为 Slides/Slide_*.xml 文本和 Resources/ 资源；
  先提取全部页面的文字、实验数据、表格、例题作为教案素材依据。
- 若用户同时提供教材版本、课时范围、实验条件、学情、输出格式等，以用户说明为准。

### 通用处理

- 先根据课件标题/章节信息判断教材版本与所属单元；常见为人教版（2024）九年级物理全一册，
  若不明确则询问用户或按新课标通用框架处理。
- 结合《义务教育物理课程标准（2022年版）》和网络有效教学资源，但以课件实际内容为骨架。

### 课时划分

- 一课时默认为 40 分钟。
- 每个课件不一定只安排一课时：需参考网络/教师用书/教学进度表，判断该课通常需要几课时。
- 生成前必须与用户确认课时数；不能因默认 40 分钟就固定为 1 课时。
- 若用户指定“临时 45 分钟”“本课按两课时”等，按用户说明执行。

## 1. 交付形式与文件命名

- 只生成详案/逐字稿：`详案.md` / `详案.docx`。
- 不再生成正常教案/简案；正常教案的全部结构要素（教材分析、学情分析、教学目标、重难点、教学准备、教学过程、板书、反思预设、参考资料）并入详案，教学过程按逐字稿写。
- 新授课文件名按课时区分，例如 `14.2第2节 热机-第1课时-详案.md`；练习课/讲评课另加“-练习课-”，例如 `14.3 热机的效率-练习课-详案.md`。
- 交付到源课件所在目录或用户指定目录；docx 放章节根级、md 放 `md文件/`（沿用工作区既有的教案归档约定）。
- 用户明确只要 Markdown 时，可省略 docx，其余要求不变。

## 2. 教案结构

### 2.1 新授课（详案·新授课）

一、教材分析
二、学情分析
三、教学目标（按核心素养四维度，每项2—4句话；句数要求不变，单句必须精简）
四、教学重难点
五、教学准备（注明实验条件；列出“实物 / 视频 / 动画 + 替代方案”）
六、教学过程
  - 分环节并标注大致时间。
  - 每个知识点标出“重点 / 难点 / 一笔带过”，重点与难点给出突破策略和大致用时，避免平均用力。
  - 教师活动细化到逐字稿程度：包括导入语、讲解、提问、追问、过渡语/衔接、小结语。
  - 写学生预设回答、可能错误。
  - 写课件使用/情景补充、板书动作（含板书时机）、设计意图。
  - 将问题串和逻辑链彻底融入教师活动；一个部分内容只选择一种更合适的方式。
  - 过渡语/衔接写成完整句子并放在相邻两段之间：联系紧密用 `过渡语（承接……→ 引出……）：……`，联系不紧密用 `衔接：……`，使上下两段自然衔接。
七、板书完整设计
八、教学反思预设
九、参考资料（课标、教材、网络资源；同时可引用外部参考资料文件）

### 2.2 练习课 / 讲评课（详案·练习课）

练习课使用独立结构（详细环节见需求 9）：错因呈现 → 错因归类精讲（嵌学生讲思路）→ 变式训练 → 分层任务 → 当堂检测 → 订正留白。

文件命名加“-练习课-”，例如 `14.3 热机的效率-练习课-详案.md` / `.docx`；md 放 `md文件/`、docx 放章节根级。

## 3. Word 排版要求

- 用真实 `.docx`（OOXML）生成，可选用 Python `zipfile` 直接写 `word/document.xml`、`word/styles.xml`，或用 `python-docx`；禁止把 Markdown 改扩展名为 `.docx`。
- 标题层级：一至三级标题必须使用 `Heading1`—`Heading3` 段落样式并写入 `w:outlineLvl`，保证 Word 导航窗格可折叠查阅。
- 正文字体：中文宋体、西文 Times New Roman，小四（12pt）；正文行距 1.5 倍，段后 6—8pt，两端对齐，首行缩进 2 字符。
- 标题字体：黑体加粗，一级 18pt、二级 14pt、三级 13pt；一级标题独立起页（`pageBreakBefore`），标题与后文不分离（`keepNext`）。
- 页边距不小于上下 2.54cm、左右 3.17cm；正文段落右端避免大量断行空白。
- 标记排版：`（板书：……）` 左缩进；过渡语/衔接按普通正文段落排在同一环节内，保持可读，不用文本框或图片。
- 表格：使用带边框表格，首行为表头；课件数据表、对比辨析表直接排成 Word 表格，不用图片或纯文本堆叠。
- 公式与符号：用文本形式排出并保证 Unicode 正确（如 Q=cmΔt、J/(kg·℃)、10³）；不用图片代替公式。
- 列表：避免 Word 内置项目符号带来的异常缩进，用普通段落加“-”或“①②③”。
- 生成后自检：重新读取 docx，确认段落样式与文本无丢失、无乱码、无样式缺失，且每部分内容完整对应 md 稿。

## 4. 需求体系

### 需求1：教学过程连贯性设计

### 1.1 过渡语 / 衔接
- 总原则：过渡只为真实存在的逻辑关系服务；关系不紧密时不硬过渡，用一句自然领起即可。
- 插入位置：必须落在相邻的两句话或两段话之间，也就是紧接上一内容的结尾、紧接下一内容的开头；不得只在环节标题后笼统标注，也不得整段堆在环节末尾。
- 使用时机：板块间或板块内前后内容具有因果、递进、对比、铺垫、并列深化关系时，必须写一句，讲清“上一个内容与下一个内容的联系点”，不能让内容或课件页面直接跳变。
- 不套过渡语：两段只是并列、或本来没有逻辑必然性时，不套“承接→引出”，改用一句自然领起。
- 篇幅要求：语句简短（一般 1—2 句），意图目的明确；按逻辑关系数量确定，不机械堆砌，但存在上述关系处不得漏。
- 在详案/逐字稿中写成教师可直接说出的完整句子。
- 禁止自问自答式设问过渡，即不得先设问再自答充作过渡（例：“速度能告诉我们谁快，那能不能告诉我们速度自己变得快不快？”）。
- 禁止“我们来看下一页”这类机械连接。
- 标注分级：
  - 联系紧密：`过渡语（承接……→ 引出……）：……`，写明衔接对象。
  - 联系不紧密：`衔接：……`，一句自然领起，不套因果句式。
- 一句话判断标准：删掉这句话学生仍能顺着听下去，就别写“承接→引出”；删掉会断层，才写过渡语。
- 某两段之间确实没有需要衔接的逻辑关系时，不硬加过渡语。
- 可借鉴“旧知引新知—冲突激思考—应用固理解”的思路设计。
- 万能过渡句黑名单（出现即删）：
  - “我们来看下一页”“接下来我们看下一张”这类机械连接；
  - “那么接下来呢？”这类无信息量承接；
  - 先设问再自答的“同学们，你们想知道为什么吗？”，随后教师自己回答；
  - 与上文无因果却用“通过刚才的学习，我们知道了……”领起新内容；
  - “有这样一句话……”“有一位科学家曾经……”这类万能引子；
  - 任何把“承接→引出”套在并列、无逻辑必然性内容上的过渡。
- 判断标准两条：① 删句测试——删掉后学生仍能顺着听，就不写“承接→引出”；② 换词测试——把过渡句里的知识内容换成别的知识点仍然成立，说明是废话，删。
- 不硬过渡时的替代表达：可用只报流程、不假装逻辑的“登记句”，如“这件事说完了，接下来处理第二件事”。登记句不算过渡语，不写“承接→引出”。
- 黑名单按“关系”判断，不按“句子”判断：同样的句子若确实在交代因果、递进关系，属合法过渡；反之，任何不带联系点的套话都算。禁止的是“没有关系却硬套”，不是某个固定句式。

### 1.2 问题串/逻辑链
- 使用时机：
  1. 课件过于简陋：只有简单结论、无推导、无实验条件、无前提情景；
  2. 学生难以理清逻辑：存在认知跳跃、抽象概念、易混点、关键转折。
- 不用时机：课件清晰、逻辑顺畅、学生能直接看懂，或常规复习、操作、练习、作业布置。
- 融入要求：选定使用后，教师活动每一步都要与问题/逻辑对应：
  1. 引问/提示；
  2. 组织思考/回答/讨论；
  3. 追问/推进；
  4. 小结/板书/过渡。
- 方式选择：每个部分只选一种。
  - 逻辑链：连续递进、学生只需判断确认时使用；
  - 问题链：关键转折、需要开放/创造性回答时使用。
- 问题链要避免只用“是不是/对不对”的封闭式提问；应有目标倒推、层层递进、前一问为后一问搭脚手架。
### 需求2：课件信息完善与讲授补白

- 每页课件问题都要判断：
  1. 学生是否知道“问什么”？
  2. 课件是否提供了回答所需条件？
- 若不明确，按五栏写：
  课件原句
  问题意图
  需补充情景
  讲授话术
  学生可能的错误想法（前概念）
- 前概念栏：概念、规律类页面必须写，纯操作、步骤类页面可省；写“学生大概率会怎么想错、错在哪”，不写空话；与“需求5 易混概念巩固”合并判断，同一处不要写两遍。
- 意图不明时先联网搜索“该课 + 该问题 + 教学设计/意图/重难点”；仍不明时询问用户。
- 在详案中，补充情景要写成教师逐字稿的一部分，不能只放在“设计意图”。
### 需求3：教学结构调整与审批

- 默认以 PPT 为准：教案中的教学环节、内容顺序、主要任务以希沃课件实际页面为骨架，不擅自脱离课件另起结构。
- 理想完整环节（供参考，非强制替换课件）：
  导入 → 新授 → 探究/实验 → 应用 → 小结 → 练习 → 作业
- 各环节之间环环相扣；有逻辑联系时使用过渡语衔接。
- 可适当申请修改/添加：
  - 如果 PPT 缺少必要环节或顺序不利于教学，可提出修改/添加建议；
  - 建议必须说明：缺什么、为什么需要、修改前后对部分和整体的影响；
  - 经用户批准后再调整，不直接改课件。
- 调整流程：
  原课件结构 → 本课脉络 → 建议调整 → 局部/整体影响 → 等待用户批准
### 需求4：板书设计（物理细化）

### 4.1 物理板书常用类型
- 提纲式：知识脉络清晰。
- 表格式：对比辨析，如串联/并联、温度/热量/内能。
- 图示式：物理过程、电路、光路、物态变化。
- 箭头/线索式：因果、递进、转化，如热传递 → 内能改变 → 温度变化。
- 综合式：核心概念 + 公式 + 应用。

### 4.2 物理板书设计原则
1. 少而精：每课时约 10—20 个关键词，不抄大段文字。
2. 直观性：用符号、简图、箭头、圈线表示物理关系。
3. 系统性：体现“概念—规律—应用”或“现象—原因—本质—应用”结构。
4. 启发性：留白、箭头指向、圈出关键条件。
5. 示范性：字母、单位、公式、符号规范，不能有科学性错误。
6. 动态性：随课堂推进逐步生成，避免一次性写满。

### 4.3 物理板书常见问题（需避免）
- 照抄课件内容。
- 只写标题不写关系。
- 公式、单位、角标不规范。
- 板书过多，挤占学生思考时间。
- 没有保留主线，学生课后无法回顾重点。
- 板书被预设死：课前一次性写满，课上不生成、不补充。
- 板书备而不用：整节课不被提问指向、不被小结使用，沦为摆设。

### 4.4 本 Skill 中的呈现方式
- 详案/逐字稿：在对应环节标“（板书时机：……；板书：……）”，并写入教师语言流程；同时在教案第七部分给出完整板书设计。
- 板书时机必须落在具体教学环节和具体讲解动作之间，如“学生说出关键词后”“讲完公式规范写法后”“小结串线时”“对比辨析时”；不得只在环节标题后笼统标注，也不得把一节课的板书动作堆在环节末尾或统一放在课前。
  示例：
      热量 ─ 过程量
        └─ 比热容 ─ Q=cm△t ─ 应用
- 允许关键词、箭头、圈线、简图，不要求语句完整。

### 4.5 板书“被用起来”硬要求（防止备而不用）
- 板书随课堂推进逐步生成，不能课前一次性写满。
- 板书要被提问指向：提问、追问时用手指或圈画对应板书内容，把学生的注意力引回结构。
- 板书要被小结使用：小结环节必须指着板书串一遍，让学生复述，不得让板书画完就挂着。
- 下课前留 30 秒，让学生对着板书复述本课主线。
### 需求5：易混概念巩固

- 每个易混点提供 3—4 个判断题或反例。
- 每题包含：题目、正确判断、错误原因、讲授要点。
- 判断题嵌入到对应教学环节，不堆在课堂末尾。
### 需求6：课时安排

- 默认每课时 40 分钟。
- 生成前查建议课时数：教师用书、教学进度表、网络教案。
- 向用户列出“建议几课时 + 每课时40分钟 + 分课时内容”。
- 用户确认后再生成；若用户临时或长久更改时长，以用户说明为准。
### 需求7：单稿输出（详案/逐字稿）

- 只生成详案/逐字稿，不再生成正常教案/简案；用户明确要求正常教案时才另行处理，并视为对默认要求的例外。
- 详案要素：教材分析、学情分析、教学目标、重难点、教学准备、教学过程、板书完整设计、教学反思预设、参考资料。
- 教学过程：教师语言、学生预设、课件补充、板书动作、设计意图、过渡语/衔接全部写实。
- 文件名：
  - `详案.md`
  - `详案.docx`
### 需求8：docx 排版便于查阅

- 生成可用的 OOXML docx，标题样式贯通导航窗格，正文字号行距适合长时间阅读与打印。
- 具体字号、行距、页边距、表格、公式、标记排版按上文“Word 排版要求（docx 便于查阅）”执行。
- 生成后重读 docx 自检，确认文本与样式完整、无乱码、无丢失。
### 需求9：练习课 / 讲评课

- 适用：练习课、试卷/作业讲评课、习题突破课。
- 结构：练习课/讲评课使用独立结构，骨架见 §2.2；环节细分见下。
- 必备环节：
  1. 错因呈现（3—5 分钟）：先批后讲，用抽样数据说明本次要解决的高频错因，只挑错得多的题；
  2. 错因归类精讲（约 20 分钟）：不按题号讲，按错因归成 2—4 类，讲一类通一类；
  3. 学生讲思路（嵌入精讲）：让做对的学生说“怎么想到的”，教师只补关键点；
  4. 变式训练（每类后 3—5 分钟）：讲完一道，立即换条件或情境再练一道；
  5. 分层任务：基础题全班必做，提升题选做，压轴题给“台阶版”；
  6. 当堂检测（5 分钟）：限时小测 + 同桌互批；
  7. 订正留白：每讲一题先留 2 分钟独立订正，再讲下一题。
- 输出要求：错因数据、学生预设回答与可能错误、变式题及参考答案，均写到逐字稿程度。
- 相关教学研究与文献见 `03-教学研究参考.md` 需求 9。
