# 对照组（不带技能）

方案要求：同一道题，带技能跑一遍、不带技能跑一遍，看分差是否 ≥10 个百分点。

## 怎么跑出来的

1. 三份无技能版详案（no-skill.md）是「只给课题、不翻技能文档、按普通老师备课的写法」写出来的：
   教材分析、学情分析、教学目标、重难点、教学过程、板书设计、教学反思一应俱全，
   但不用本技能的格式约定——没有课程安排表，没有 board 围栏，没有逐字引用来源，也不是逐字稿体量。
2. docx 用技能内的 build_docx.py 从 md 转换，目的是排除「没有 Word 文件」这种与内容无关的差异。
3. 判分时把 no-skill.md/.docx 顶替 evals/base-0X/reference/ 里的文件，用同一个 run_evals.py 打分：

   python3 scripts/run_evals.py --evals-dir <临时目录> --json evals/baseline/no-skill.json

4. 两边的模型判分（P 项）由同一名评审按同一口径阅卷，结论写在各自 verdicts.yaml。

## 结果（2026-10-27）

| 基准 | 带技能 | 不带技能 | 差值 |
| --- | --- | --- | --- |
| base-01 15.2 新授课 | 100% | 45% | +55 个百分点 |
| base-02 16.1 演示实验课 | 100% | 44% | +56 个百分点 |
| base-03 17.1 练习课 | 100% | 50% | +50 个百分点 |

三套都超过方案要求的 10 个百分点，门2 的对照条件成立。

注意：对照组的失分里有几项属于「格式约定」（没有课程安排表、没有 board 围栏、没有逐字引用来源）。
这不是说普通教案不好，而是本技能把「可校验的结构」当成交付标准；在内容项上，
带技能版的学生预设、过渡语、错因归类也确实更全。
