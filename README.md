# dsh-grade9-physics-lesson-plan-skill

> 版本：v7.0.0

九年级物理教案生成 Skill，基于希沃白板 `.enbx` 或类似课件生成/修改教案。

## 功能特点

- **默认一课时 40 分钟**，生成前确认课时数
- **单稿输出**：只生成详案/逐字稿（一个 Word + 一个 Markdown）
- **两套结构**：新授课（详案·新授课）与练习课/讲评课（详案·练习课）分开，不能混用
- **连贯教学**：过渡只为真实逻辑关系服务；禁止自问自答式设问与万能过渡句，弱联系用“衔接：”
- **板书**：标“板书时机”，并要被提问指向、被小结使用；字迹差有替代方案（打印贴、磁条分色、电子板书）
- **练习课**：先测后讲、按错因归类精讲、学生讲思路、变式训练、分层任务、当堂检测、订正留白
- **Word 便于查阅**：标题样式可导航，正文小四 1.5 倍行距，表格与公式规范
- **课件补白**：问题指向不明时先查清意图，补足讲授所需情景；概念/规律类页面写“学生可能的错误想法（前概念）”
- **易混辨析**：每个易混点配 3–4 个判断题或反例；**问题链 / 逻辑链**仅在课件简陋或学生难理清逻辑时使用
- **实物优先**：教学准备必须列“实物 / 视频 / 动画 + 替代方案”，演示前先预测、后说结论
- **重难点可视**：教学过程标出每条知识点“重点 / 难点 / 一笔带过”
- **课堂时段策略**：下午第一节 / 晚自习 / 体育课后 的应对（见参考资料附录）
- **以 PPT 为准**：教学环节以课件为骨架，调整需先申请批准

## 使用方法

1. 把本仓库内容放入支持 Skill 的 Agent 环境：用户级 `/root/.dsh/skills/generate-9th-grade-physics-lesson-plan/` 或项目级 `.agents/skills/generate-9th-grade-physics-lesson-plan/`。
2. 向 Agent 提供 `.enbx` 课件路径或说明课时信息。
3. Agent 加载 `SKILL.md`（入口），按其索引按需读取 `references/`，默认输出详案 Word + Markdown。

## 目录结构

```text

├── SKILL.md                    # 入口：触发 / 确认 / 流程 / 硬约束 / 索引
├── references/

│   ├── 02-教学设计细则.md       # 通用要求、使用注意事项、教学目标精简、交付前自检
│   ├── 03-教学研究参考.md       # 关键观点与文献（按需求号）+ 分时段附录
│   └── 04-技能维护规范.md       # 目录结构、命名、同步、版本、变更记录
└── README.md                   # 本说明
```
