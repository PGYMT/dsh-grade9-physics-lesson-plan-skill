# dsh-grade9-physics-lesson-plan-skill

九年级物理教案生成 Skill，基于希沃白板 `.enbx` 或类似课件生成/修改教案。

## 功能特点

- **默认一课时为 40 分钟**
- **生成前确认课时数**：每个课件不一定只安排一课时，会参考教材/教学进度/教师用书建议课时数，并在生成前与用户确认
- **连贯教学**：在板块间、板块内逻辑紧密处插入合适的过渡语，避免课件页面直接跳变
- **问题指向明确**：课件问题指向不明时，先查清该问题的具体指向/意图，再写入教案
- **课件情景补充**：课件上只有简单语句时，补充讲授时所需的具体情景，避免说服力不足
- **板书精简**：采用关键词 + 箭头 / 圈线等结构图式，体现本节课重点，不追求完整语句
- **易混辨析**：常见易混淆概念通过简单判断、小例子帮助学生理解巩固
- **问题链 / 逻辑链**：将问题串和逻辑链条彻底融入教师活动，一个部分只选择一种更合适的方式

## 使用方法

1. 将本 Skill 放入支持 Skill 的 Agent 环境中，例如 `.agents/skills/` 目录。
2. 向 Agent 提供 `.enbx` 希沃白板课件路径或说明课时信息。
3. Agent 按本 Skill 要求生成教案，默认输出 Word + Markdown。

## 生成流程

1. 解包 `.enbx`（ZIP 容器），提取每页文字、表格、实验数据、例题。
2. 判断教材版本与章节，结合 2022 版课标和网络资源。
3. 生成教案前确认：课时数、是否为 40 分钟一课、是否调整课件结构。
4. 按“教材分析—学情分析—教学目标—重难点—教学准备—教学过程—板书设计—教学反思预设—参考资料”输出完整教案。
5. 检查目标句数、过度语、问题指向、板书精简、易混判断等是否符合要求。
